# Fabrya SEO — commercial mission through 22 October 2026

## Terminal goal

Obtain at least one **real paying customer whose first attributable acquisition is Google organic** by 2026-10-22.

Everything else is an intermediate metric. Impressions, rankings, CTR, indexed pages and demos matter only insofar as they increase the probability of:

`Google organic → qualified visit → demo/intent → checkout → confirmed payment`.

## Scope

No sector boundary. Search across every query, profession, problem, solution, use case, comparison, feature or commercial intent that is genuinely compatible with Fabrya.

Use observed Search Console demand when available, but do not restrict discovery to currently observed sectors.

## Opportunity allocation

Prioritize actions by:

1. commercial intent;
2. existing Google evidence or strong product/query fit;
3. realistic speed to materially improve visibility before the deadline;
4. ability to show a real Fabrya proof/demo;
5. probability of converting to a paid customer;
6. low policy/ranking risk.

Prefer a small number of materially stronger pages over mass production.

## Allowed asymmetries

Exploit legitimate ranking opportunities aggressively:

- underserved search intent;
- weak or generic competing results;
- fragmented topical coverage;
- poor title/snippet alignment;
- underused images and visual proof;
- weak internal linking;
- duplicate/canonical signal dilution;
- missing structured data where appropriate;
- query fan-out / adjacent sub-intents;
- pages already being tested by Google;
- improvements supported by real Search Console evidence.

## Absolute anti-spam guardrails

Never use cloaking, doorway pages, fake locations, mass near-duplicate AI pages, hidden text, keyword stuffing, fake reviews, fake customers, purchased/spam backlinks, manipulated clicks, expired-domain abuse, false product claims or deceptive structured data.

Do not create a page unless a real user landing on it receives distinct value.

## Decision rule

If an action does not plausibly improve the probability of a real Google-organic payment by the deadline, deprioritize it.

When data is weak, run the smallest reversible experiment that can produce learning quickly.

## Output contract

Each productive cycle should leave durable evidence of:
- data used;
- opportunity selected;
- action proposed or executed;
- expected commercial impact;
- policy/risk check;
- measurement criterion;
- next decision.

PASS only when payment + reliable Google organic attribution are both proved.
